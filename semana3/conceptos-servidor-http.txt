Responde con tus propias palabras.

1. ¿Qué es un cliente en la web?

Respuesta: Es algo que le hace una consulta a un servidor lejano

2. ¿Qué es un servidor?

Respuesta: Es una maquina que analiza las solicitudes y da respuestas

3. ¿Qué es HTTP explicado de forma sencilla?

Respuesta: el lenguaje que usa el navegador al comunicarse con el servidor

4. ¿Qué es una request o solicitud?

Respuesta: Es pedir información a un servidor

5. ¿Qué es una response o respuesta?

Respuesta: Es dar información a un servidor

6. ¿Para qué sirve el método GET?

Respuesta: Para recibir información de un servidor

7. ¿Para qué sirve el método POST?

Respuesta: para hacer y dar interacción a un servidor

8. ¿Qué hace el comando npm start en esta práctica?

Respuesta: Activa el servidor

9. ¿Qué mensaje viste al abrir http://localhost:3000?

Respuesta: Bienvenida comunidad. Este es el servidor de participación.

10. ¿Cómo se relaciona un servidor con una plataforma participativa?

Respuesta: Un servidor deberia permitir que la comunidad interactue de forma adecuada.
